# Sistema Andenes
Este repositorio contiene **recursos visuales estáticos** (imágenes) utilizados en el **Sistema de Andenes**, principalmente para su consumo en dashboards (Power BI).

## 📌 Propósito
Centralizar imágenes como:
- Logos
- Íconos
- Fondos visuales

con el objetivo de:
- Contar con **URLs públicas y estables**
- Facilitar su integración en dashboards
- Evitar dependencias de permisos de SharePoint u otros servicios restringidos

## ⚠️ Consideraciones
- Este repositorio **no contiene información sensible** ni código productivo.
- Solo deben subirse **recursos visuales aprobados para uso público**.
- Cualquier cambio en imágenes puede impactar dashboards en producción.
